### Project Title *

**Blizkperse**

### Category *

**Privacy / Consumer / Payments**

### Description *

**Blizkperse makes crypto payments confidential and painless across any EVM chain.**

Organizations today cannot pay teams on-chain without exposing their entire salary structure and vendor relationships. **Blizkperse blocks reverse-engineering** of payment flows by breaking the on-chain link between Payer and Recipient.

**How it works:**

1. **Frictionless Onboarding**: Participants log in with social accounts (via Para) and instantly get an embedded wallet. They "Subscribe" to a Payer (Organizer) with one click.
2. **Subscription-Based Payouts**: Payers see a list of their subscribers. They simply select recipients, input amounts of any stablecoin, and execute a single transaction into a Shielded Pool.
3. **Private Claims**: Recipients claim their funds using a Zero-Knowledge proof. No link between sender and receiver on-chain.
4. **Multi-Chain**: The same shielded pool contract and ZK proof system deploys on any EVM chain. Live on Monad (Chain 143) and Celo (42220).

**Key Features:**

- **Anti-Reverse Engineering**: Competitors cannot analyze your payout/grant strategy.
- **Payroll Privacy**: Employees cannot see each other's salaries.
- **Privacy First (ZK)**: Payments are processed via Zero-Knowledge proofs (Noir circuits, Poseidon2 commitments).
- **Social Login**: No seed phrases required for recipients (Para SDK embedded wallets).
- **Bulk Distribution**: One transaction pays multiple users.
- **Chain-Agnostic**: Deploy on any EVM chain with the same contracts and proofs.
- **Chain-Adaptive UI**: Neutral grayscale by default, colors activate per selected chain.

**Use Cases:**

- Payroll privacy
- Rewards & airdrops
- DAO treasury distributions
- x402 agent payments (AI agents pay for API access using shielded transfers)

**Future Roadmap:**

- **x402 Integration**: HTTP 402 protocol for AI agent autonomous payments.
- **More Chains**: Expanding beyond Monad and Celo to any EVM chain on demand.
- **Agentic Infrastructure**: Designed to be the payout layer for AI Agents. Agents can autonomously trigger payouts to contributors for completed tasks.
