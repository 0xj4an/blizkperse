## Color Palette (Monad / Cyberpunk)

We use a "Dark Mode First" aesthetic to fit the Monad ecosystem.

| Role | Color | Hex | Tailwind Utility |
| :--- | :--- | :--- | :--- |
| **Background** | **Deep Void** | `#0E0E12` | `bg-[#0E0E12]` |
| **Surface** | **Zinc 900** | `#18181B` | `bg-zinc-900` |
| **Primary** | **Monad Purple** | `#836EF9` | `text-[#836EF9]` / `bg-[#836EF9]` |
| **Secondary** | **Neon Cyan** | `#22D3EE` | `text-cyan-400` |
| **Accent** | **Electric Pink** | `#F472B6` | `text-pink-400` |
| **Text** | **White** | `#FFFFFF` | `text-white` |
| **Muted** | **Zinc 400** | `#A1A1AA` | `text-zinc-400` |

### Usage Rules
-   **Buttons**: `bg-primary` text-white rounded-xl hover:opacity-90.
-   **Cards**: `bg-surface` border border-white/10.
-   **Gradients**: Use heavy gradients of Purple->Cyan for hero text.
    -   `bg-gradient-to-r from-[#836EF9] to-cyan-400`

## Typography
**Font Family**: `Inter` or `Outfit` (Google Fonts).

-   **Headings**: Bold, Tight Tracking.
-   **Body**: Regular, Relaxed.
